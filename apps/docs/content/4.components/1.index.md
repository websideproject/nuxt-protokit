# Components Overview

All components are globally auto-imported by the module. No manual import is needed.

## Main components

| Component | Description |
|-----------|-------------|
| `ProtoTool` | Full tool renderer — form + results + viz + CRUD. Use this for most cases. |
| `ProtoDashboard` | Renders `schema.layout` (tabs, rows, columns). `ProtoTool` uses it when a layout is set. |
| `ProtoForm` | Form fields only — `fields` (props `fields`, `model`), grouped by `sections` when given. |
| `ProtoCrudList` | CRUD list for a single collection: add, edit, delete, search, presets. |
| `ProtoCrudTable` | Read-only table of a collection's items (`tableColumns`). |
| `ProtoCrudModal` | Modal editor for a single collection item, with a draft for new items. |
| `ProtoCrudInlineForm` | The inline add / edit form `ProtoCrudList` uses. |
| `ProtoStatGrid` | Displays a `stats` array as a responsive tile grid. |
| `ProtoViz` | Renders one `VizDef` (props `viz`, `context`). |
| `ProtoCard` | Renders a single schema card definition. |
| `ProtoDetailCard` | Read-only field / value grid for one record, formatted by each field's `format`. |
| `ProtoSection` | Titled box, optionally collapsible. |
| `ProtoBadge` | Small coloured label (used for result badges). |
| `ProtoActionBar` | Toolbar with copy/export/reset action buttons. |
| `ProtoCalendar` / `ProtoCalendarView` | Calendar backed by Y.js / driven by your own events. See [ProtoCalendar](/components/proto-calendar). |
| `ProtoDebugPanel` | Slideover showing every open document. Not gated — render it only in development. |
| `ProtoCorruptionModal` | Non-dismissible modal shown when IndexedDB corruption is detected. Mount it once in `app.vue`. |

## Item panel components

Use these components to extend a collection item's detail view with specialized input and display panels. Each panel takes a `panelDef` (the panel configuration) and the current `item`; the time-series and URL panels emit `update` with a patch to save back to the collection.

| Component | Description |
|-----------|-------------|
| `ProtoItemPanelTextTemplate` | Renders template-generated text sections with per-section char counters, copy buttons, and a Regenerate action. |
| `ProtoItemPanelTimeSeries` | Date + metric snapshot form with a sortable history table showing the last seven entries. |
| `ProtoItemPanelUrlInput` | Single URL field with save-on-Enter and a Save button, emitting a patch via `onConfirm` or a direct field assignment. |

## Field components (internal)

These are used inside `ProtoForm` and are not normally referenced directly. They are globally registered in case you need to use them in custom UIs.

| Component | Renders |
|-----------|---------|
| `ProtoFieldText` | `<UInput type="text">` |
| `ProtoFieldNumber` | `<UInput type="number">` |
| `ProtoFieldTextarea` | `<UTextarea>` |
| `ProtoFieldSelect` | `<USelectMenu>` |
| `ProtoFieldSegmented` | A group of `<UButton>`s |
| `ProtoFieldToggle` | `<USwitch>` |
| `ProtoFieldRange` | `<input type="range">` with min / value / max labels |
| `ProtoFieldRating` | Star rating buttons |
| `ProtoFieldColor` | `<input type="color">` |
| `ProtoFieldDate` | `<UInput type="date">` |
| `ProtoFieldTags` | Tag input with chip display |
| `ProtoFieldLinkedResponses` | Per-question textarea grid |
