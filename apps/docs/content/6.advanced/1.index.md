## When to Use Advanced Patterns

Start with the standard schema and composables. Reach for these guides when you need to:

- **Share schemas across tools** — extract common fields into reusable fragments and compose them per tool
- **Build a product toolkit** — bundle multiple `ProtoTool` instances with shared state and cross-tool computed values
- **Replace built-in UI** — swap the default field renderer for a custom component without forking the library
- **Guard by role and state** — hide or lock fields and collections per role, combined with runtime conditions
- **Go headless** — keep the persistence and drop the UI: your own components on `usePrototype` / `useProtoList`
