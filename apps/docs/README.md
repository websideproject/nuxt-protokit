# nuxt-protokit docs

The documentation of [`@websideproject/nuxt-protokit`](../../packages/nuxt-protokit), built with [Docus](https://docus.dev).
It is published at [websideproject.com/docs/nuxt-protokit](https://websideproject.com/docs/nuxt-protokit).

```bash
# from the repository root
bun install
bun run dev:docs    # http://localhost:3000
bun run build:docs
```

Pages live in `content/`; screenshots used by the pages live in `public/screenshots/`.
